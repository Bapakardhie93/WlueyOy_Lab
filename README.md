# WlueyOy

WlueyOy is a simple menstrual cycle tracking application for the Mobile
Programming practicum. This repository contains the React Native, TypeScript,
and Expo implementation.

## Run the project

Install dependencies and start Expo:

```bash
npm install
npm start
```

The Module 1 Contributor A implementation is in `src/app/index.tsx` and
demonstrates a TypeScript type, an array of objects, and a `.map()` loop.
